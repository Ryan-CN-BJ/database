# 基础概念概述

欢迎来到 AI SDK 的基础概念部分。本部分将帮助您了解 AI 和大型语言模型（LLM）的核心概念。

## 什么是 AI SDK？

AI SDK 是一个 TypeScript 工具包，旨在简化 AI 应用程序的开发。它提供了统一的 API 来与各种 AI 模型提供商交互，包括 OpenAI、Anthropic、Google 等。

## 核心概念

### 大型语言模型 (LLM)

大型语言模型是一种基于深度学习的 AI 系统，能够理解和生成人类语言。它们可以执行各种任务，如文本生成、翻译、问答等。

### 模型提供商

AI SDK 支持多种模型提供商，每个提供商都有其独特的优势和特点。常见的提供商包括：

- **OpenAI** - 以 GPT 系列模型闻名
- **Anthropic** - Claude 系列模型的开发者
- **Google** - Gemini 系列模型
- **xAI** - Grok 模型
- **Azure** - 微软的云 AI 服务
- **Amazon Bedrock** - 亚马逊的 AI 服务平台

### 提示工程

提示工程是设计和优化提示以获得最佳模型输出的过程。一个好的提示可以显著提高模型的性能和输出质量。

### 工具调用

工具调用允许 AI 模型与外部工具和 API 交互。这使模型能够执行计算、访问实时数据、操作文件等。

### 流式传输

流式传输是一种技术，允许模型在生成内容时逐步返回结果，而不是等待完整响应。这提供了更好的用户体验，特别是对于长时间运行的任务。
